# Timeless Cuisine Restaurant — Information System Analysis & Design

## Overview

**Timeless Cuisine Restaurant** is a System Analysis and Design project that focuses on analyzing restaurant business processes and designing a proposed information system to support **ordering, payment, inventory, procurement, supplier management, and reporting**.

The project translates identified business problems into structured system models and process documentation.

## My Contribution

My contribution focused on the **System Analysis & Design** part of the project, including:

- Analyzing existing business problems and operational processes
- Developing system requirements and process flows
- Creating and documenting UML and system analysis diagrams
- Modeling system interactions, data relationships, and process states
- Preparing technical documentation for the proposed system
